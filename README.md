# E-commerce Data Analysis Using Python

## Project Overview
This project analyzes online retail sales data using Python to identify sales trends, top-selling products, and customer purchasing patterns.

## Technologies Used
- Python
- Pandas
- Matplotlib
- OpenPyXL

## Key Features
- Data cleaning and preprocessing
- Monthly revenue analysis
- Top-selling product analysis
- Country-wise sales analysis
- Customer purchase analysis
- Charts and visualizations

## How to Run
Install the required libraries:

```bash
python -m pip install pandas matplotlib openpyxl
```

Run the project:

```bash
python sales_analysis.py
```

## Project Outputs
The `outputs` folder contains CSV summaries and charts generated by the analysis.

## Dataset
Online Retail dataset from the UCI Machine Learning Repository.
